## ⚡ Key Interactive Features
- **Interactive Solar Load Estimator Tool**: Select household appliances (bulbs, fans, fridges, TVs, ACs) and desired blackout backup hours to dynamically compute recommended Inverter kVA, Battery units, and Solar Panel wattage with 1-click cart bundling.
- **Contractor & Bulk Quote RFQ System**: Builders & contractors can submit schedule of materials for wholesale quotes.
- **Direct WhatsApp Order Checkout**: Auto-generates formatted order message with full itemized breakdown and delivery address sent directly to `08137271212`.
- **Slide-Over Shopping Cart**: Includes quantity adjustments, instant promo code discount (`GLOW10` for 10% off), subtotal, and checkout receipt generator.
- **Full Backend API (Node.js & Express)**: Auth sessions, orders persistence, and admin state management.

## 🚀 How to Run Locally

```bash
# 2. Start the Express server (starts on http://localhost:3000)
npm start
```
